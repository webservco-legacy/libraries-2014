# libraries-2014

My PHP helper classes of 2014: a mysqli wrapper (insert, update and select with bound results), an IMAP client
(mailboxes and message lists), a singleton base, an object parser, and the trade-list queries of my site. A historical
archive, kept read-only: the PHP code of its time: not safe to deploy today, kept for its history.
